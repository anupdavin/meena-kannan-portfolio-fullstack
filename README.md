## 🚀 Key Features

1. **Matrix Rain Canvas Background**:
   - High-performance HTML5 Canvas streaming digital glyphs with glow effects.
2. **Terminal Hero Section**:
   - Real-time Java 21 / Spring Boot 3 code typewriter animation.
   - Live enterprise metrics (7+ Years Exp, 40+ Deployments, 99.99% SLA Uptime, 10K+ RPS).
3. **Clean Architecture & System Specifications (`$ cat about_me.txt`)**:
   - Visual breakdown of Presentation, Application, Domain (DDD), and Infrastructure layers.
   - Core engineering philosophy and principles.
4. **Interactive Tech Stack (`$ ls -la /skills/`)**:
   - Categorized skills: Backend & JVM, Cloud & DevOps, Databases & Streams, Frontend & UI, Architecture & Testing.
   - Live search filter and hover detail benchmark inspector.
5. **Enterprise Projects Showcase (`$ ./showcase --projects`)**:
   - Filterable projects with interactive architecture modals, metrics, challenges vs. solutions, and code snippet viewer with copy support.
6. **Career Timeline (`$ git log --experience`)**:
   - Visual milestone timeline displaying engineering achievements and tech stacks.
7. **Interactive In-Browser Terminal CLI (`#terminal`)**:
   - Working terminal accepting commands (`help`, `whoami`, `skills`, `projects`, `experience`, `hire`, `architecture`, `contact`, `easteregg`, `clear`).
8. **Contact & Dispatch Terminal**:
   - Left terminal info printout + interactive dispatch form with validation and SLA guarantees.
9. **In-Browser AI Assistant (`MeenaBot`)**:
   - Floating cyberpunk bot answering questions on Meena's background, projects, availability, and contact details.

## 💻 Development & Cross-Device Testing

### 🌐 Access URLs
- **Local Machine**: [http://localhost:5173](http://localhost:5173)
- **Mobile / Local Network**: `http://<your-local-ip>:5173` (e.g. `http://192.168.1.152:5173` on same Wi-Fi)

```bash
# Install dependencies (if not already present)
npm install

# Start Vite server (host: true enabled for network access on phones/tablets)
npm run dev

# Run automated tests
npm test

# Build for production
npm run build

# Preview production build locally
npm run preview
```
